# 효과음 슬롯

여기에 아래 이름으로 파일을 넣으면 **합성음 대신 그게 나온다.** (`.ogg` 우선, 없으면 `.wav`)
없으면 `core/sfx.gd` 가 그 자리에서 합성한 임시음이 나온다 — 파일이 하나도 없어도 게임은 소리가 난다.

| 파일명 | 언제 | 길이 권장 | 성격 |
|---|---|---|---|
| `step.ogg` | 유닛이 한 칸 이동 | 0.05~0.10s | 아주 짧고 건조하게. 한 틱에 여러 번 난다 |
| `attack.ogg` | 공격 모션 시작 | 0.05~0.12s | 휘두름/발사 |
| `hit.ogg` | 피해가 들어감 | 0.08~0.15s | 타격. attack 과 반드시 달라야 한다 |
| `death.ogg` | 유닛 사망 | 0.25~0.45s | 하강음 |
| `heal.ogg` | 회복 | 0.15~0.30s | 상승음 |
| `special.ogg` | 궁극기 발동 | 0.35~0.60s | 이 게임에서 제일 특별한 소리 |
| `defend.ogg` | 방어 태세 | 0.08~0.15s | 둔탁하게 |
| `click.ogg` | 버튼/카드 클릭 | 0.02~0.05s | |
| `buy.ogg` | 카드 구매 | 0.08~0.15s | |
| `victory.ogg` | 전투 승리 | 0.5~1.5s | |
| `defeat.ogg` | 전투 패배 | 0.5~1.5s | |

## 규격

- **모노**, 22.05kHz 이상, `.ogg`(권장) 또는 `.wav`
- **-6dB 정도로 정규화**해서 넣을 것. 게임에서 다시 -6dB 를 먹이므로 원본이 크면 찢어진다
- 앞뒤 무음을 잘라낼 것. 앞에 무음이 있으면 타격이 늦게 들린다
- `step` 과 `hit` 은 한 틱에 여러 번 겹친다. 잔향이 길면 뭉갠다

## 주의

같은 이름은 45ms 안에 한 번만 난다(`Sfx.DEDUPE`). 같은 파형이 셋 겹치면
진폭이 3배가 되어 "커진 소리" 가 아니라 "깨진 소리" 로 들리기 때문이다.
